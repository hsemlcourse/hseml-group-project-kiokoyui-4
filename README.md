## Описание задачи

В рамках проекта решается задача многоклассовой классификации уровня игровой зависимости пользователей на основе их поведенческих, социальных и физиологических характеристик.

**Задача:** Классификация

**Датасет:** Gaming and Mental Behavioral Dataset (синтетический набор данных о поведении игроков, психическом состоянии и образе жизни) https://www.kaggle.com/datasets/sharmajicoder/gaming-and-mental-health/data

**Целевая переменная:**  
`addiction_category` — категориальный признак с тремя классами:
- low (низкий уровень зависимости)
- medium (средний уровень зависимости)
- high (высокий уровень зависимости)

**Целевая метрика:** F1-score (macro)

Дополнительно используются:
- Accuracy
- Confusion Matrix для анализа ошибок

Выбор F1-macro обусловлен необходимостью равномерного учета качества классификации по всем классам, независимо от их распределения.
