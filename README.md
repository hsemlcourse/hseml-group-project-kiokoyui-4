## Описание задачи

В рамках проекта решается задача многоклассовой классификации уровня игровой зависимости пользователей на основе их поведенческих, социальных и физиологических характеристик.

**Задача:** Классификация

**Датасет:** Gaming and Mental Behavioral Dataset (синтетический набор данных о поведении игроков, психическом состоянии и образе жизни) https://www.kaggle.com/datasets/sharmajicoder/gaming-and-mental-health/data

**Целевая переменная:**  
`addiction_category` — категориальный признак с тремя классами:
- low (низкий уровень зависимости)
- medium (средний уровень зависимости)
- high (высокий уровень зависимости)

**Целевая метрика:** F1-score (macro)

Дополнительно используются:
- Accuracy
- Confusion Matrix для анализа ошибок

Выбор F1-macro обусловлен необходимостью равномерного учета качества классификации по всем классам, независимо от их распределения.

## Результаты

Ниже приведены результаты сравнения моделей машинного обучения по метрикам Accuracy и F1 macro на тестовой выборке.

| Модель | Accuracy | F1 macro | Примечание |
|--------|----------|----------|------------|
| Logistic Regression | 0.692 | 0.697 | Лучшая линейная модель, сильный baseline |
| Random Forest | ~0.690 | ~0.695 | Стабильная модель, но без прироста качества |
| KNN | ~0.589 | ~0.589 | Худший результат, чувствителен к размерности |
| Gradient Boosting | 0.700 | 0.701 | Лучшая ансамблевая модель |
| XGBoost | ~0.698 | ~0.699 | Сильная модель, но без превосходства над GB |
| Voting Classifier | ~0.699 | ~0.700 | Усреднение моделей без значимого улучшения |
| Stacking Classifier | ~0.698 | ~0.699 | Сложная ансамблевая модель без прироста качества |
| AdaBoost | ~0.691 | ~0.694 | Слабее других ансамблевых методов |

---

## Лучшая модель

Наилучший результат по метрике F1 macro показала модель **Gradient Boosting (0.701)**.

Несмотря на то, что разница с Logistic Regression и другими ансамблевыми методами является незначительной, Gradient Boosting был выбран как финальная модель, так как:

- обеспечивает наивысшее качество среди всех протестированных моделей;
- устойчиво работает с нелинейными зависимостями;
- демонстрирует стабильные результаты на различных выборках данных.

Таким образом, Gradient Boosting является наиболее сбалансированной моделью с точки зрения качества и устойчивости.
